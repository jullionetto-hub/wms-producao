Entrada Manual RepositorSupervisão

Para que serve: controlar a chegada de mercadoria (entrada de estoque), buscar o código de barras de um produto e fazer o inventário físico com o coletor. Funciona no computador e no celular.

Quem vê o quê:

  • Supervisão, Gestão e Reposição: as 3 abas — Entrada de Estoque, Código de Barras e Inventário.
  • Separação, Checkout e Embalagem: só a consulta Código de Barras (menu "Código de Barras").

Como chegar: menu Entrada Manual (Supervisão, Gestão, Reposição) ou Código de Barras (os demais perfis). Na Reposição, a aba ENTRADA do celular leva ao registro de entrada de produto.

Aba Entrada de Estoque

Uma entrada é um lote: uma planilha com os produtos que chegaram e onde cada um deve ser guardado. O repositor vai conferindo item a item, informando quanto realmente abasteceu.

1) Criar um lote (importar o arquivo)

  1. Em Importar novo arquivo, dê um Nome do lote (ex.: "3R Import 28/05").
  2. Clique ou arraste o arquivo (.xlsx, .xls ou .csv). O sistema reconhece as colunas pelo nome (sem diferenciar maiúscula): Código (obrigatório; aceita cod, sku, ref), Descrição (produto, nome), Quantidade (quant., qtd, qty; vazio = 1) e Endereço (local, localização).
  3. Confira a prévia e confirme. Mensagem: "N itens importados! Abrindo lote..."
MensagemSignifica
Arquivo vazio.Não há linhas.
Coluna Código não encontrada.O cabeçalho não tem uma coluna de código reconhecida.
Nenhum item válido encontrado.Todas as linhas estão sem código.
Erro ao ler arquivo / Erro ao importarArquivo corrompido ou falha de servidor.

2) Lista de lotes

Filtre por DE/ATÉ (começa no 1º dia do mês até hoje) e clique em Filtrar. Cada lote mostra o progresso e as contagens de itens Pendentes, Abastecidos, Parciais e Não encontrados. Clique no lote para abrir. O botão Excel exporta o lote.

3) Abastecer os itens de um lote

  1. Dentro do lote, o topo mostra a barra de Progresso (x/y) e os quatro contadores. Use a busca ("Código ou descrição...") e os filtros Todos / Pendente / Abastecido / Parcial / Não encontrado. A lista tem paginação.
  2. Cada linha (desktop) ou cartão (celular) tem: CÓDIGO, DESCRIÇÃO, QTD ESP. (esperada), QTD ABAST. (campo com − / +), ENDEREÇO, OBSERVAÇÃO, STATUS e SALVAR.
  3. Endereço: é validado ao digitar. Formatos aceitos: letras/números com barra e hífen, por exemplo D106, ZA387, C099/VERT-C82-CX18, U080, U087/VERT-U01-CX13. Endereço vazio ou fora do padrão mostra erro na própria linha. Ao sair do campo, o sistema consulta o histórico daquele código no servidor.
  4. Informe a quantidade abastecida e toque em Salvar (a linha) — "CÓDIGO salvo!". Sem mudança: "Nenhuma alteração para salvar".
  5. Se a quantidade for maior que a esperada, abre "Quantidade acima do esperado — Realmente chegaram N unidades?"; se for menor (e maior que zero), abre "Quantidade abaixo do esperado — Confirma salvar com quantidade incompleta (X de Y)?". Confirme ou corrija.
  6. O status é definido pela quantidade: 0 = Não encontrado (vermelho); igual ou maior que a esperada = Abastecido (verde); entre 1 e a esperada = Parcial (amarelo); antes de salvar = Pendente (cinza).
  7. Para salvar vários de uma vez, ajuste os itens e clique em Salvar Tudo: só envia os que mudaram ("N itens salvos!"; sem mudança: "Nenhum item com alterações para salvar.").
  8. ← Voltar retorna à lista de lotes. O lote pode ser excluído ("Lote excluído.").
Cada salvamento é gravado na hora; se a internet cair, a linha mostra erro e a quantidade não foi salva. Salve de novo quando a rede voltar.

Aba Código de Barras

Para que serve: quando o leitor não consegue ler a etiqueta física de um produto, busque-o aqui e bipe o código de barras exibido na tela.

Passo a passo

  1. Digite o código do produto ou o EAN no campo "Código do produto ou código de barras (EAN)..." e clique em Buscar (ou Enter).
  2. O sistema mostra o nome, o código e o código de barras desenhado em fundo branco (de propósito, para o leitor conseguir ler). Bipe a tela.
  3. Para outro produto, use Nova busca.
MensagemSignifica
Produto não encontrado. Verifique o código e tente novamente.O código não existe no catálogo.
Produto sem código de barras cadastrado.O catálogo tem o produto mas não o EAN.

Importar o catálogo (Supervisão)

O catálogo vem do arquivo barras.xlsx (códigos, nomes, código de barras, saldo e localização). Clique em "Clique para importar barras.xlsx" e selecione o arquivo (.xlsx, .xls ou .csv). Mensagem: "Catálogo importado! N produtos." Produtos que já existem são atualizados; novos são criados. Avisos: "Arquivo vazio.", "Coluna Código não encontrada.", "Nenhum produto válido."

Aba Inventário

Para que serve: contar fisicamente o estoque e comparar com o saldo do sistema, mostrando as divergências.

Criar um inventário

  1. Em Criar novo inventário, digite um nome (ex.: "Inventário Geral Jul/2026"). Sem nome: "Informe um nome para o inventário."
  2. Em FILTRAR POR RUA (opcional) escolha Todos os produtos ou uma rua (para contar só uma parte do estoque).
  3. Clique para criar. O sistema monta a lista a partir do catálogo. Se o catálogo estiver vazio: "Catálogo vazio. Importe o barras.xlsx na aba Código de Barras primeiro." Sucesso: "Inventário criado com N produtos!"

Lista de inventários

Cada inventário aparece como Em andamento ou Concluído, com o progresso da contagem. Abra um para ver o painel.

Painel do inventário

  • Progresso da contagem (contados / total) e uma tabela com CÓDIGO, NOME, LOCALIZAÇÃO, SALDO SIS. (saldo do sistema), CONTADO, DIF. (diferença) e STATUS. Busca por código ou nome e filtro por rua.
  • Status do item: pendente (não contado), ok (contado igual ao saldo) e divergente (contado diferente do saldo).
  • Contar manualmente: digite a quantidade no campo do item e use SALVAR ("CÓDIGO contado!"). Depois que o inventário é concluído a edição trava: "Inventário concluído — edição bloqueada."
  • Sync: atualiza as localizações do inventário com as do catálogo ("N endereços atualizados do catálogo!").
  • Concluir: encerra o inventário ("Inventário concluído!"). Não dá para contar mais.
  • Excel: exporta o inventário. Excluir (Supervisão) remove tudo ("Inventário excluído.").

Coletor de Dados (contagem no celular)

  1. No painel, toque em Coletor (Coletor de Dados). Opcionalmente escolha a Rua que você vai contar (ou Todas as ruas).
  2. A câmera abre ("Câmera ativa — aponte para o código de barras"). Se o aparelho não suportar leitura pela câmera, use o campo de texto ("Ou digite / cole o código manualmente"). Se a câmera for bloqueada: "Câmera não autorizada. Use o campo de texto abaixo."
  3. Bipe o produto. A tela mostra o item, a Rua, o Saldo do sistema e a Quantidade contada. Cada nova leitura do mesmo código soma +1 (há uma pausa de 2 segundos entre leituras do mesmo código) e o sistema salva sozinho, com um bip de confirmação.
  4. Para digitar a quantidade, ajuste o campo e toque em Salvar (Enter): "CÓDIGO salvo com N! Aponte para o próximo."
  5. Para trocar de produto sem salvar, use ↩ Cancelar / próximo.
  6. Alerta de rua errada: se você escolheu contar a rua X e bipa um item cuja localização é de outra rua, aparece em vermelho ITEM NA COLMEIA ERRADA! com "Rua Y — você está contando a rua X". Leve o item para o lugar certo ou registre a divergência.
  7. Código que não está no inventário: "\"código\" não encontrado no inventário."
  8. Toque em ← Painel para voltar.
Bipar o mesmo produto várias vezes soma as unidades: bipe uma vez para cada peça (ou digite o total). Conte tudo que está no endereço, inclusive o que está em caixas fechadas, para a comparação com o sistema fazer sentido.

Dúvidas comuns

SituaçãoSolução
Quantidade abastecida ficou errada num loteReabra o lote, corrija o número e salve de novo; o status se ajusta.
Endereço não aceitaUse só letras, números, barra e hífen (2 a 30 caracteres), sem espaços.
A câmera não lêAproxime/afaste, melhore a luz ou digite o código.
Contei errado no inventárioEnquanto estiver "Em andamento", é só contar de novo e salvar.

Colmeias SupervisãoGestão

Para que serve: controlar o estoque de bancadas/colmeias pré-abastecidas por SKU (um estoque manual extra, fora do corredor principal). O sistema calcula o saldo ao vivo: quantidade abastecida menos o que já saiu em pedidos concluídos daquele código desde o abastecimento. Quando o saldo cai até o mínimo, a colmeia entra em alerta, para você abastecer antes de faltar.

Como chegar: menu Operação › Colmeias (Supervisão e Gestão).

Cartões de resumo

Colmeias ativas, Total cadastrado, Total consumido, Saldo total, Em alerta e Esgotadas.

Faixa de alerta

Quando há colmeias no mínimo, uma faixa vermelha lista: "N colmeia(s) no estoque mínimo" com cada código, saldo e mínimo (ex.: MVELS8008 (saldo 40 / mín. 50)). Colmeia sem mínimo definido (0) só entra em alerta quando esgota.

Passo a passo

  1. Nova colmeia: clique em Nova Colmeia e preencha Código do produto (ex.: MVELS8008), Descrição (opcional), Quantidade abastecida (ex.: 200), Endereço da colmeia e Estoque mínimo (alerta) (ex.: 50). Clique em Adicionar: "Colmeia cadastrada!"
  2. Abastecer: na linha, clique em Abastecer, informe a Quantidade a adicionar e confirme: "Abastecimento registrado!" O histórico de abastecimentos fica guardado.
  3. Editar endereço ou estoque mínimo: informe o Novo endereço/Novo estoque mínimo e salve ("Endereço atualizado!" / "Estoque mínimo atualizado!").
  4. Remover: confirma "Remover colmeia? A colmeia do código X será removida da lista." → "Colmeia removida!"

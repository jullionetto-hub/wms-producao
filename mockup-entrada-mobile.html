🔒 VALIDAÇÃO DE ENDEREÇO — REGRAS
🔒 Como funciona a Validação de Endereço
3 camadas de proteção contra erros de estoque
CAMADA 1 — FORMATO DO ENDEREÇO
Padrão esperado
A-01-02
Letra (corredor) · Número (rua) · Número (posição)
A-01-02 B-03-01 C-12-04 XZ-99 A01-02 abc
CAMADA 2 — HISTÓRICO DO PRODUTO
✅
Endereço Correto
Formato válido + produto já foi guardado aqui antes
A-01-02 → ✅ Endereço confirmado
⚠️
Endereço Diferente do Histórico
Formato válido, mas produto costuma ir para outro local. Pede confirmação antes de salvar.
B-03-05 →
⚠️ Histórico: B-03-01
Clique para confirmar mesmo assim
❌
Formato Inválido — Bloqueado
Não segue o padrão. Botão salvar fica bloqueado até corrigir.
XZ-99 →
❌ Formato inválido
Use o padrão: A-01-02
CAMADA 3 — FLUXO DE CONFIRMAÇÃO
1
Usuário digita o endereço → sistema valida o formato em tempo real
2
Se válido, consulta o histórico do produto para checar se o endereço bate
3
Se endereço diferente: popup de confirmação "Este produto costuma ir para B-03-01. Quer salvar em B-03-05?"
4
Se formato inválido: botão salvar bloqueado + mensagem de erro inline
5
Ao salvar com sucesso: atualiza o histórico com o novo endereço confirmado
